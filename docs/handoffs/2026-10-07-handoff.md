## 4. What the UI shows today, and what it doesn't

**The Portfolio page shows:**
- Total value (verified, priced only), wallet count, asset count.
- Notices: incomplete syncs (with the provider's own reason), failed syncs, stale data, price-source
  disagreements, thin liquidity, hidden tokens.
- **By wallet** (the default): wallet → chain → positions, with amount; price (with source, age, and
  `stale` / `sources disagree` / `low confidence` badges); market cap, FDV, and liquidity; and
  value (`thin liquidity` badge). Also inline Rename, "Not tracked on X · Track", and per-chain
  sync status and notes. Expanding a row shows the asset ID and Mark verified / Mark spam.
- **By asset:** merged across wallets, with a per-wallet breakdown.
- **Show hidden:** unverified and spam tokens, which are never counted in totals.

**The System page shows** health (API, database, worker), how each chain is read, and whether a
Coinbase key is detected.

## 5. Helping the user check that things are correct

**"A balance looks wrong"**
- Compare against an explorer: Solscan (Solana), Etherscan (Ethereum), or
  `robinhoodchain.blockscout.com` in a browser (it blocks scripts, not people).
- Check that chain's last sync status and notes in the wallet card, or in `sync_runs`.
- Every balance snapshot links to the raw provider response it came from (`raw_records`), so you
  can see exactly what the provider returned.

**"A value looks wrong"** It's almost always the price. Compare sources:
- DefiLlama: `https://coins.llama.fi/prices/current/solana:<mint>`
- Jupiter: `https://lite-api.jup.ag/tokens/v2/search?query=<mint>`
- DexScreener: `https://api.dexscreener.com/tokens/v1/<chain>/<address>`

Policy (ADR 0015): tokens are priced on-chain first (Jupiter / deepest DexScreener pool), with
DefiLlama for native assets and as a cross-check; a gap over 25% is flagged. The moin case in the
01a build log is the worked example.

**"A token is missing"**, in order of likelihood:
1. It's hidden as unverified (Show hidden; Mark verified to count it).
2. It's on Robinhood Chain (needs the Alchemy network).
3. It's an NFT (skipped).
4. Its balance is zero (not stored).
5. Its contract has no readable decimals (skipped, with a note on the sync).

**"The total doesn't match what I expect":**
- It counts only verified, priced assets; hidden ones are estimated separately.
- Venues (Coinbase, Hyperliquid) aren't included yet.
- Robinhood Chain tokens aren't included until the Alchemy network is enabled.
- Values are at market price, not what a position could be sold for.

## 7. Rules and gotchas for the next session

- **Workflow:** every roadmap step has a brief (`docs/briefs/NN-slug.md`) → build → build log
  (`docs/build-logs/YYYY-MM-DD-slug.md`) → mark ✅ in the brief and `ROADMAP.md`. Work not on the
  roadmap gets a step and brief first. Decisions get an ADR. Directory rules go in that directory's
  `CLAUDE.md` (the user wants `CLAUDE.md` only, not `AGENTS.md`).
- **The dev database holds the user's real accounts.** Never truncate or reset it, and never delete
  accounts you didn't create. Hand-added test data gets a `test-` label and is removed by exact ID.
  Automated tests use `talewinds_test` only. Rehearse data-touching migrations on a `pg_dump` copy
  first.
- **Secrets:** never print `.env` values (the Alchemy key is set). Mask keys in any `curl` you run.
- **Don't commit or push unless asked.**
- **The toolchain is newer than most docs and memory:** TypeScript 7, pnpm 12 (installed via npm;
  corepack can't install it), Vite 8, Vitest 5, pg-boss 12, AI SDK 7. Check APIs against the type
  definitions in `node_modules`.
- **Supply chain:** pnpm refuses versions published less than 7 days ago, enforces
  `trustPolicy: no-downgrade`, and blocks install scripts. Add dependencies deliberately.
- **`pnpm check` must pass** before work is done. It includes integration tests and starts
  Postgres.
- **zsh gotcha:** don't name a shell variable `path`; it overwrites `PATH`.
- **About the user:** wants intent explained plainly (lead with why, no unnecessary abstractions);
  values record keeping; fluent in Python but chose TypeScript; trades Robinhood Chain
  (medium/long-term) and Solana (memecoins); wants TypeSafe's Jev model for agents later.
  Persistent memory notes for this project load automatically in this directory.
