## 1. The project in brief

Talewinds is a personal crypto platform for one user (you). It covers your portfolio across every
wallet, chain, and venue; automated token research; wallet investigation; and later, agentic
trading. Priority 1 is research automation and portfolio management; priority 2 is agentic
trading.

- [VISION.md](../VISION.md): the vision, principles, and ADR index (ADRs 0001–0019).
- [ROADMAP.md](../ROADMAP.md): every step, with one brief each in [briefs/](../briefs/).
- [CONTEXT.md](../CONTEXT.md): the glossary (coin, category, theme, scope, small balance, venue
  asset, …).
- [build-logs/](../build-logs/): what was actually built, deviations, verification, and gaps.
- The root `CLAUDE.md`, plus one per directory: the rules for working in each part.

Stack: a TypeScript monorepo (pnpm 12, Turborepo, TypeScript 7, Node 24), Postgres 18 in Docker,
Drizzle, a pg-boss job queue, a Hono API, a Vite + React dashboard (Tailwind v4, TanStack Router and
Query), and the `tw` CLI.

## 6. For the UI work

**Where the dashboard lives** (`apps/web/src`, rules in `apps/web/CLAUDE.md`):
- `routes/portfolio.tsx`: the page. It holds the scope picker, stat tiles, notices
  (`collectNotices`), the allocation card, the holdings toggles (By wallet / By asset, Show small
  balances, Show hidden), and the wallet list.
- `components/portfolio/Overview.tsx`: `OverviewStats` (tiles) and `AllocationCard` (the views
  Asset / Category / Theme / Wallet / Chain, the donut and table, coin rows that expand into their
  holdings, tag badges, and "Tag" opening the editor).
- `components/portfolio/Tags.tsx`: `TagEditor` (category chips, theme toggles, new tags inline) and
  `TagManager` (rename and delete).
- `components/portfolio/WalletGroups.tsx`: wallet and venue cards, chain sections, folded
  small-balance rows, the 24h column, Rename and Remove. `HoldingsTable.tsx` is the by-asset
  table, and `cells.tsx` holds the shared cells (price, 24h change, market cap, value,
  verify/spam actions, the small-balances row).
- `components/charts/Donut.tsx`: an inline-SVG donut. `components/ui.tsx` has Card, Stat, Badge,
  Button, Notice, and Segmented.
- `lib/api.ts`: the typed client (`hc<AppType>`; types come from `apps/api`). `lib/format.ts` has
  the formatters (`formatUsd`, `formatShare`, `formatChangePct`, `shareFraction`, …).
- `styles.css`: design tokens, and the chart series colors as plain `:root` variables.

**Data:** one call, `GET /api/portfolio/holdings?wallet=<id>&hidden=1`, returns the whole page.
`overview` has `byCoin`, `byAsset`, `byCategory`, `byTheme`, `byWallet`, `byChain`,
`concentration`, and `change24h`. `wallets` is the list of groups, where `kind` is `wallet` or
`venue`. The response also includes `small`, `hidden` (with `largest`), `tags`, `walletOptions`,
`totals`, and `quality`. All the math is server-side (`packages/portfolio/src/holdings.ts`).
Amounts and shares arrive as decimal strings.

**Rules that matter for UI edits:**
- **No float math on money.** Format with `lib/format.ts`. `shareFraction` is for chart geometry
  only.
- **Use the semantic tokens** (`bg-surface`, `text-muted`, `border-border`, …). Never put two
  classes that set the same property on one element.
- **Chart colors:** assign `--color-series-1…5` **by rank within each chart**, then
  `--color-series-other` (gray) for the rest, "Small balances", and "Uncategorized"/"No theme". The
  palette is color-blind safe only as neighbors in that order (checked with the dataviz skill's
  validator). Every chart has a table with every value next to it. Load the `dataviz` skill before
  making new charts.
- **Tailwind v4 only emits `@theme` variables that appear in class names**, which is why the
  series colors are plain `:root` variables (a variable built in a loop renders black).
- **New logic goes in packages.** The web shapes data it receives and never computes totals or
  shares.
- **Keep data age and incompleteness visible** (badges and notices).

**How to check UI changes:** the dev server hot-reloads. Headless Chrome works well for
screenshots and clicks: drive it over the DevTools protocol from Node 24 (built-in `WebSocket`).
Launch `Google Chrome --headless=new --remote-debugging-port=<port> --user-data-dir=<tmp>`, connect
to the page's `webSocketDebuggerUrl`, then use `Page.navigate`, `Runtime.evaluate` (to click, and to
override `window.confirm`), and `Page.captureScreenshot`. A plain `--screenshot` run also works but
hangs on exit because the page keeps polling. Kill the processes you start.

## 7. Rules and gotchas

- **Workflow:** every step gets a brief, then the build, then a build log, then ✅ in the brief and
  ROADMAP. Work that isn't on the roadmap gets a step and brief first; small additions use a letter
  suffix (02e, …). Decisions get an ADR. Directory rules go in that directory's `CLAUDE.md` (never
  AGENTS.md).
- **Your real data:** the dev database holds your real wallets. Never reset it, and never remove a
  wallet unless you ask. Hand-added test data gets a `test-` name and is removed by ID afterwards.
  Add test wallets through the CLI (no sync) and between sync ticks, so no raw records (immutable)
  are created for them. Automated tests use `talewinds_test` only.
- **Secrets:** never print `.env` values; check presence with `awk` on variable names only.
- **Commits:** don't commit or push unless asked.
- **Toolchain:** newer than most memory (TypeScript 7, pnpm 12, Vite 8, Vitest 5, Tailwind 4.3,
  Drizzle 0.45, Zod 4). Check APIs in `node_modules`. `pnpm check` must pass before work is done.
- **Migrations:** edit the schema, run `pnpm db:generate`, read the SQL, give it a descriptive name
  (rename the file and its `_journal.json` tag before it's applied anywhere), then `pnpm db:migrate`.
  The CLI prints "Migrations up to date" after applying.
- **Process management on macOS:** `pgrep -P` needs a pattern. To stop dev servers, find them by
  working directory (`lsof -a -p <pid> -d cwd`).
- **Provider quirks found this session:** Hyperliquid's `spotMetaAndAssetCtxs` contexts **aren't
  aligned with the markets by index** (match by name or token index). Hyperliquid's `subAccounts`
  returns a bare `null`. mempool.space may drop connections. Coinbase has no USDC-USD market (it
  uses exchange rates). Robinhood Chain explorer blocks scripts.
- **You:** you want intent explained plainly (lead with why, no unneeded abstractions). You value
  record keeping. You trade Robinhood Chain (medium and long term) and Solana memecoins, and you
  hold ZEC and HYPE as majors.
