# Build log — Scaffold

- **Date:** 2026-09-27
- **Brief:** [`00-scaffold`](../briefs/00-scaffold.md)

## Summary

The monorepo, database, job queue, worker, API, dashboard shell, CLI, guardrails, and
documentation are in place and verified end to end. `pnpm dev` brings the whole stack up with one
command, and `pnpm check` is green. No product features yet; V0a and V0b build on this.

## What was built

**Workspace and tooling**
- pnpm 12 workspace + Turborepo (`dev`, `typecheck`, `test`, `build` tasks).
- Strict shared tsconfig (`tooling/tsconfig/`), TypeScript 7, ESM only, `.ts` import extensions,
  `erasableSyntaxOnly`.
- Biome for lint + format; Vitest for tests.
- Supply-chain settings in `pnpm-workspace.yaml`: 7-day `minimumReleaseAge`,
  `trustPolicy: no-downgrade`, install scripts blocked unless allow-listed, exact pins.
- `tooling/scripts/check-boundaries.ts`: package dependency matrix, restricted `execution`
  package, cross-package relative-import detection, web may import `@talewinds/api` only as types.

**Infrastructure**
- `docker-compose.yml`: Postgres 18, bound to localhost only, with a healthcheck.
- `.env.example` → `.env` (git-ignored); every process validates its env at startup.

**packages/core**: CAIP-2 chain registry (Ethereum `eip155:1`, Robinhood Chain `eip155:4663`,
Solana mainnet), venue list, address validation/normalization, account model (`ownership`,
`kind`, entity kinds, `NewAccountInput`, canonical refs), exact-amount math (`RawAmount`, `Dec`,
format/parse, bigint-safe `toJson`), job contracts (`JOBS.systemPing`), `parseEnv`. 11 unit tests.

**packages/db**: Drizzle schema + migration `0000_init` — `entities` (single `self` entity enforced
by a partial unique index), `accounts` (CHECK constraints on kind, ownership, and row shape),
`worker_heartbeats`. `uuidv7()` IDs. Client, migrator, ping, and repos (`addAccount`,
`listAccounts`, `ensureSelfEntity`, heartbeats + pruning).

**packages/runtime** (new, see deviations): env loading, pino logger with redaction, typed pg-boss
queue wrapper (`send`/`work`/`waitForResult`), `startRuntime` with ordered shutdown.

**apps/worker**: queue + `system.ping` handler, 15s heartbeat, prunes heartbeats older than 24h.

**apps/api**: Hono on `127.0.0.1:3001` — `GET /api/health` (database latency + worker freshness;
503 when unhealthy) and `GET /api/accounts`. `AppType` exported for the typed client. 3 tests.

**apps/cli** (`pnpm tw`): `db migrate`, `status`, `ping`, `account add`, `account list`.

**apps/web**: Vite + React + TanStack Router/Query + Tailwind v4 with semantic design tokens. Pages:
Portfolio (lists owned accounts), Research (disabled input, placeholder for V0b), System (live
health, refreshed every 5s). Typed API client via `hc<AppType>`.

**Stub packages**: `sources`, `ai`, `portfolio`, `research`, `investigation`: an empty entry point
plus a `CLAUDE.md` describing purpose, planned structure, and rules.

**Docs**: `VISION.md` (supersedes the initial brief), `CONTEXT.md` glossary, ADRs 0001–0013,
`CLAUDE.md` in the root, `docs/`, `tooling/`, every app, and every package, and this brief/log pair.

## Deviations from the plan

1. **Added `packages/runtime`.** It wasn't in the approved layout. api, worker, and cli all need
   the same bootstrap (env, logger, db, queue, shutdown), and the CLI discussion promised shared
   startup code. Without it, that code would be copied three times.
2. **Replaced dependency-cruiser with a custom script.** TypeScript 7 is the native compiler, and
   tools relying on the TS compiler API are a compatibility risk. pnpm's strict resolution plus a
   ~150-line matrix check covers our rules with zero dependencies. Recorded in ADR 0006.
3. **shadcn/ui setup deferred** to the first slice that needs real components. Tailwind and the
   design tokens are in place.
4. **No CI workflow yet.** There's no GitHub remote; `pnpm check` is the gate. Add a workflow when
   a remote exists.
5. **pnpm installed globally via npm** (`npm install -g pnpm@12.5.1`). Corepack 0.34 can't install
   pnpm 12, whose package now ships a native binary. Noted in the README.
6. **esbuild's install script is explicitly denied** (`allowBuilds: esbuild: false`). Its platform
   binary arrives via optionalDependencies and works without it (verified via tsx).

## Verification performed

- `pnpm check` green: Biome (78 files), boundaries, typecheck across 12 packages, 14 tests.
- **Boundary checker catches violations:** three planted violations (core → db dependency, a
  relative import from research into db, a value import of `@talewinds/api` in web) all failed the
  check. Removed afterwards.
- **Typed client is really typed:** a probe file using `@ts-expect-error` on a nonexistent response
  field and a nonexistent route type-checked (both were errors). Removed afterwards.
- **CLI against the real database:** registered a Robinhood Chain wallet (EVM address lowercased,
  CAIP-10 ref), a duplicate (reported "Already registered"), a Coinbase venue, and a tracked Solana
  wallet (case preserved). Rejected an EVM address on Solana and a missing `--chain`/`--venue` with
  clear errors. **These test accounts were deleted afterwards; the database starts empty.**
- **Queue round trip:** `pnpm tw ping` returned from the worker in ~0.3–1s. After a hot reload,
  the new worker process answered.
- **`pnpm dev`:** Postgres healthy → migrations → api, worker, and web all started;
  `/api/health` returned 200 through the dashboard's `/api` proxy.
- **Dashboard rendered** (headless Chrome screenshots) for Portfolio, Research, and System with
  live data. Found and fixed an active-nav-highlight bug (conflicting color classes).
- **Browser bundle:** `vite build` succeeds (451 KB JS / 144 KB gzip). A scan for server code
  (`drizzle`, `pg-boss`, `pino`, `node:fs`, `DATABASE_URL`) found none.
- **Clean shutdown:** stopping the processes released their ports and left no orphans.

## Known gaps and notes

- **No authentication.** The API binds to `127.0.0.1`. Auth is required before any network
  exposure (ADR 0003).
- **No database integration tests yet.** Repos were verified by hand through the CLI. Decide a
  test-database strategy in V0a (e.g. a separate database in the same container).
- **Job latency is poll-bound** (~0.3–1s). pg-boss supports LISTEN/NOTIFY for instant pickup if
  needed.
- **Pretty logs key off `NODE_ENV`.** Production must set `NODE_ENV=production` to get JSON logs.
- `pnpm tw …` prints pnpm's `$ tsx …` echo line before command output; that's pnpm behavior.
- The dashboard imports `@talewinds/core` (and so zod) for chain names, which accounts for part of
  the bundle size. Fine for now.
